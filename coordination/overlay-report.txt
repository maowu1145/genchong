Implemented:
- All specified service actions/extras and static isRunning/isPaused/count APIs.
- Stable instance IDs; repeated characters allowed; maximum six active bodies and windows.
- One tightly bounded TYPE_APPLICATION_OVERLAY window per pet; no fullscreen drawing/input
  window. Transform-aware local sprite bounds include compression/stretch/rotation; drawing
  uses world center minus window origin. Physics has separate screen bounds, main-body
  circle collision shapes and artwork edge extents. Thin decorative tails are not colliders.
- Shared fixed 1/120s physics, max four substeps, three all-pairs contact passes. Gravity,
  limited throws, restitution, tangent friction/rotation, held/fixed/tool-open kinematic
  bodies, collision-normal spring compression and near-area-preserving stretch remain real.
- Softness maps continuously: stiffness 420..100, damping 24..12, compression .18..42;
  midpoint exactly restores old stiffness=260 and damping=18. Render deformation is a
  whole-texture spring, not mesh/local soft-body deformation.
- Main-thread render scheduling: normal render target 30fps, drag target 60fps, low-power
  rendering target 15fps; shared physics ticks independently. Timing is bounded, not a
  measured fps claim. Settled nonanimated bodies stop frame callbacks. Gravity change,
  removal of support, drag/throw and size/settings changes wake the world.
- Screen-off/paused stops frame loop and sensor listeners, cancels gestures and removes
  transient UI/cues; no wake lock. Minute-scale quiet-hour check only while awake/unpaused.
- Accelerometer low-pass gravity, fallback TYPE_GRAVITY, fallback fixed downward gravity
  with user notice when absent. Rotation mapping follows upstream. Comfort uses separate
  TYPE_LINEAR_ACCELERATION or raw-minus-filtered residual, dead zone, damping and limits.
- Comfort: two 16dp narrow, bounded non-touchable edge windows; intensity/opacity and
  comfort_reset_token honored; immediate off removes windows. Damps gravity, bounce,
  throws/deformation and suppresses sprite loops. No health efficacy claim.
- Non-touchable bubble/recycle alpha .35 and cue alpha <=.6 at WINDOW level. Bubble is
  removed before drag and new feedback never opens one during recycling, keeping maximum
  non-touchable overlap .74 (=1-.65*.4), below Android's documented .8 limit. Pet and menu
  rectangles remain touchable inside their bounds; transparent corners are not pixelwise
  pass-through. All-window touch behavior still needs Android 12+ device verification.
- Raw-coordinate VelocityTracker avoids false velocity from moving overlay origins.
  PENDING / DRAGGING / LONG_PRESS / IDLE branches are exclusive; system slop cancels hold;
  long-press release cannot throw/tap/delete; multi-touch/CANCEL aborts; recycle only during
  drag and only recalls on release inside the visible drop area.
- Tap menu: tools, pin/unpin, sizes 56/88/112/144dp, recall, pause/resume all, close;
  scrollable in short/landscape displays and closes after 15s. Long press opens tools.
  Visible FeatureActivity lifecycle pauses that instance and restores it when stopped.
- Positions merge into freshly loaded instances on drag end, stop, screen off, task remove,
  settle and 5s checkpoints, preserving concurrent mood/settings updates. STOP retains saved
  instances for explicit later restoration; REMOVE deletes that instance. START_NOT_STICKY
  avoids automatic resurrection after a user/system stop; no background forced start.
- Display/configuration updates rescale normalized placement and clamp bounds. System bars,
  cutout, API30+ delivered IME insets constrain positions; no focus-stealing pet windows.
- Permission revoke uses AppOps watcher plus runtime checks; teardown removes windows,
  receivers, callbacks and sensors. Notification opens GengMainActivity and stops all.
- Explicit-package dynamic FEEDBACK / RELOAD_SETTINGS broadcasts update only running service;
  character-wide feedback selects only one instance. Temporary images plus bounded bubble.
- Original alpha untouched. PetCatalog async preload used; static and animation foot anchors
