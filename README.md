# 小鼻嘎（Android）

小鼻嘎是一个原生 Android 悬浮桌宠。授予悬浮窗权限并点击“放出小鼻嘎”后，它会悬浮在其他应用上方，并随手机重力方向滚动、碰撞和反弹。

## 运行

1. 用 Android Studio 打开本目录。
2. 等待 Gradle 同步完成，将 Android 8.0（API 26）或更高版本的手机连接到电脑。
3. 点击 Run 安装应用。
4. 首次打开时授予通知和悬浮窗权限，然后点击“放出小鼻嘎”。

建议使用真机测试，模拟器通常没有可自然操作的重力传感器。

## 主要实现

- `MainActivity`：权限引导和小鼻嘎开关。
- `OverlayPetService`：前台服务、透明全屏悬浮层、重力传感器监听。
- `PetView`：60 FPS 左右的二维运动、阻尼、边界碰撞与反弹。

Android 的陀螺仪测量旋转速度，不能单独确定重力方向。因此本项目优先使用系统融合后的 `TYPE_GRAVITY` 传感器；设备不提供它时，会回退到经过低通滤波的加速度计。
